# MY HOME FOOD OS

Offline bilingual household food and house-care application.

## Android
GitHub Actions generates the Android platform and builds a release APK.
The artifact is named **my-home-food-os-android**.

Features:
- FR/EN
- Cameroon meals
- Weekly meal planning
- Budget and spending
- Pantry and low-stock tracking
- Freezer status
- School snack planning
- House-care checklist
- Gas and kitchen reminders
- Local persistence
- Home Copilot entry point
